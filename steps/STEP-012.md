# STEP-012: 국가 경계 및 선택 강조 대비 개선

## 목표

- 지도에서 나라별 경계를 더 뚜렷하게 보이게 하고, 선택 강조 색상을 검은색 계열로 정리한다.

## 작업 범위

- 일반 국가 경계선 색상과 두께를 강화한다.
- 선택 국가 stroke를 검은색 계열로 변경한다.
- hover/pressed 상태도 더 선명한 경계로 정리한다.
- 선택 국가 popout 핀 색상을 노란색에서 검은색 계열로 맞춘다.

## 완료 기준

- 나라별 경계가 이전보다 명확하게 보인다.
- 선택 국가가 노란색 대신 검은색 계열 테두리로 강조된다.
- 라벨 핀과 선택 테두리의 시각 톤이 일관된다.
- lint/build 검증을 통과한다.

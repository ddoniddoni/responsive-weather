# STEP-015: 도/주 선택 및 지역 날씨 패널 연결

## 목표

- 국가 내부의 도/주를 클릭하면 우측 상세 날씨 패널이 해당 지역 기준으로 갱신되도록 만든다.

## 작업 범위

- 선택 상태를 국가 선택과 행정구역 선택으로 구분한다.
- ADM1 행정구역 클릭 이벤트를 추가한다.
- 지역 이름, 부모 국가, 지역 코드 타입을 정의한다.
- mock 날씨 데이터 구조를 국가/지역 확장이 가능한 형태로 보완한다.
- 우측 패널 제목과 상세 정보를 선택 지역 기준으로 표시한다.

## 완료 기준

- 도/주를 클릭하면 선택 지역 이름이 지도와 패널에 표시된다.
- 지역 선택 시 우측 패널 데이터가 해당 지역 기준으로 갱신된다.
- 국가 선택 상태와 지역 선택 상태가 명확히 분리된다.
- 기존 국가 클릭 기반 상세 패널 동작이 망가지지 않는다.
- lint/build 검증을 통과한다.

## 작업 체크리스트

- [ ] 지역 선택 타입 정의
- [ ] ADM1 클릭 이벤트 연결
- [ ] mock 날씨 데이터 구조 확장
- [ ] 우측 패널 지역 표시 반영
- [ ] lint/build 검증

# STEP-013: 국가 선택 시 지도 카메라 확대 및 포커스 이동

## 목표

- 사용자가 국가를 클릭했을 때 해당 국가가 더 잘 보이도록 지구본을 회전하고 확대한다.

## 작업 범위

- 선택 국가의 중심 좌표를 기준으로 지구본 회전값을 계산한다.
- 국가 클릭 시 자동으로 선택 국가가 화면 중심에 오도록 이동한다.
- 선택 국가 클릭 후 확대값을 자연스럽게 올린다.
- 기존 수동 드래그 회전, +/- 버튼, 마우스 휠 확대/축소 기능은 유지한다.
- 자동 이동이 과도하게 튀지 않도록 애니메이션 또는 단계적 상태 변경을 검토한다.

## 완료 기준

- 국가 클릭 시 선택한 국가가 중심부에 가깝게 보인다.
- 국가 클릭 후 기존보다 선택 국가를 더 크게 볼 수 있다.
- 사용자는 자동 확대 이후에도 드래그와 zoom 컨트롤을 계속 사용할 수 있다.
- 모바일과 데스크톱에서 지도 영역이 깨지지 않는다.
- lint/build 검증을 통과한다.

## 작업 체크리스트

- [x] 선택 국가 중심 좌표 기반 회전 계산
- [x] 국가 클릭 시 자동 확대 적용
- [x] 자동 포커스 이후 수동 조작 유지 확인
- [x] 모바일/데스크톱 레이아웃 확인
- [x] lint/build 검증

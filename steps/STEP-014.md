# STEP-014: 선택 국가 ADM1 행정구역 경계 표시

## 목표

- 국가를 선택하면 해당 국가의 도/주 단위 행정구역 경계를 지도 위에 표시한다.

## 작업 범위

- 무료 행정구역 데이터 소스 후보를 확정한다.
- 우선 후보는 geoBoundaries ADM1 GeoJSON/TopoJSON 데이터로 검토한다.
- 선택 국가 ISO3 코드 기준으로 ADM1 데이터를 가져오는 로직을 분리한다.
- 지도 컴포넌트는 국가 레이어와 행정구역 레이어를 구분해서 렌더링한다.
- 데이터 로딩, 실패, 미지원 국가 fallback UI를 처리한다.

## 데이터 소스

- geoBoundaries API `current/gbOpen/{ISO3}/ADM1/` 응답의 `gjDownloadURL`을 사용한다.
- `gbOpen` 데이터는 geoBoundaries 안내 기준 CC BY 4.0 라이선스 기반으로 사용하며, 지도 하단에 출처를 표시한다.

## 완료 기준

- 지원 국가를 클릭하면 도/주 경계가 지도 위에 표시된다.
- 행정구역 데이터가 없는 국가는 기존 국가 선택 화면이 깨지지 않는다.
- API/데이터 로딩 로직은 컴포넌트 내부에 길게 작성하지 않는다.
- 지도와 날씨 패널 상태가 과도하게 섞이지 않는다.
- lint/build 검증을 통과한다.

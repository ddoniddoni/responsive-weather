# STEP-017: 날씨 반응형 상세 지표 카드 추가

## 목표

- 국가 또는 지역을 클릭했을 때 우측 상세 패널의 온도, 체감온도, 습도, 바람 정보를 날씨 상태에 맞는 시각적 카드로 표현한다.

## 작업 범위

- 기존 `WeatherReactiveButton`의 sunny/rainy/cloudy 시각 효과를 재사용 가능한 컴포넌트로 분리한다.
- 온도, 체감온도, 습도, 바람 지표를 표시하는 새 날씨 지표 카드 컴포넌트를 만든다.
- 우측 `WeatherDetailPanel`의 단순 회색 지표 박스를 새 컴포넌트 기반 카드로 교체한다.
- 날씨 상태는 색상만으로 구분하지 않고 텍스트 label/value도 함께 제공한다.
- 다크/라이트 모드에서 카드 대비와 가독성을 유지한다.

## 완료 기준

- 우측 패널의 4개 지표가 새 컴포넌트로 렌더링된다.
- sunny, rainy, cloudy 상태에서 버튼과 유사한 시각 효과가 지표 카드에도 반영된다.
- 기존 국가/지역 선택과 패널 표시 동작이 유지된다.
- 모바일/데스크톱 카드 그리드가 깨지지 않는다.
- lint/build 검증을 통과한다.

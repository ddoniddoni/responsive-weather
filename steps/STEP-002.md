# STEP-002: 날씨 시각화 기반 작업 정의

## 목표

- 실시간 오버레이 방향 재정의 이후 처음 구현할 화면 작업을 명확히 정리한다.
- 지구본이 복잡한 레이더 제품처럼 보이지 않으면서도 전 세계 날씨 상태를 직접 전달하도록 만든다.
- 상단 브랜드, 폰트, 테마 토글을 정리해 앱의 첫인상을 더 완성도 있게 만든다.

## 작업 항목

### 1. 지도 위 지구 날씨 표현

기존 `react-simple-maps` 지구본 위에 가벼운 날씨 오버레이를 올린다.

첫 구현 권장 방식:

- 모든 국가가 아니라 대표 날씨 지점부터 시작한다.
- 각 대표 지점을 `Marker` 오버레이로 렌더링한다.
- 마커는 날씨 상태 아이콘 또는 형태와 짧은 온도 라벨을 함께 보여준다.
- 상세 날씨 값은 기존 날씨 패널 또는 모바일 시트에 유지한다.
- 사용자가 지구본 날씨 레이어를 켜고 끌 수 있도록 보이는 토글을 추가한다.
- 필요하면 먼저 mock 오버레이 데이터로 UI 동작을 검증하고, 이후 Open-Meteo를 연결한다.

이 방식을 선택하는 이유:

- 현재 프로젝트가 이미 지구본에서 `Marker`를 사용하고 있다.
- Step 001에서 정의한 `WeatherOverlayPoint[]` 모델과 잘 맞는다.
- 모든 국가를 계속 요청하는 비싼 구조를 피할 수 있다.
- 대표 지점 수를 제한하면 모바일에서도 읽기 쉽다.
- 이후 색상 밴드, 가벼운 열지도 레이어, 실제 API 기반 데이터로 확장하기 쉽다.

첫 오버레이 흐름:

```txt
대표 날씨 지점
-> WeatherOverlayPoint[]
-> WorldMap 오버레이 토글
-> 지구본 위 compact 마커
-> 마커 클릭 시 날씨 상세 선택 또는 패널 열기
```

초기 마커 규칙:

- 첫 구현에서는 대표 지점을 8-12개 이하로 제한한다.
- 국가 선택 팝아웃 또는 주요 지도 인터랙션을 가리지 않는다.
- 색상만으로 날씨 의미를 전달하지 않고 아이콘, 라벨, aria label, tooltip 중 하나 이상을 사용한다.
- 아주 작은 화면에서는 라벨을 숨기거나 단순화한다.
- 이 Step에서는 레이더 타일, 위성 레이어, 애니메이션 타임라인을 추가하지 않는다.

### 2. 왼쪽 상단 브랜드 정렬

왼쪽 상단 브랜드 블록을 정리한다.

- `RW`가 정사각형 안에서 시각적으로 가운데에 오도록 맞춘다.
- `Responsive Weather` 텍스트가 로고와 세로 기준으로 자연스럽게 정렬되도록 한다.
- 모바일에서는 브랜드가 과하게 넓어지지 않게 유지한다.
- 검색 영역 너비가 바뀌어도 로고와 텍스트가 흔들리지 않게 한다.

### 3. 폰트 개선

앱의 기본 폰트 방향을 더 보기 좋게 정리한다.

- 현재 기본 폰트를 더 깔끔하고 한국어 UI에 어울리는 산세리프 계열로 개선한다.
- 숫자 날씨 값, 국가 코드, 짧은 기술 라벨에는 읽기 좋은 mono 폰트만 제한적으로 사용한다.
- 글자 간격은 음수로 줄이지 않는다.
- 제목, 버튼, 패널 텍스트가 라이트/다크 모드에서 일관된 인상을 주도록 맞춘다.

선호 방향:

- 기본 UI 폰트는 가능하면 `Pretendard`를 사용한다.
- 설치나 적용 방식이 부담되면 `next/font`와 호환되는 Google font 조합을 우선 사용한다.

### 4. 해와 달 테마 토글

테마 토글을 텍스트 중심의 다크/라이트 표현에서 해와 달 상태 표현으로 바꾼다.

- 라이트 모드는 해 상태로 표현한다.
- 다크 모드는 달 상태로 표현한다.
- 스크린 리더를 위한 명확한 `aria-label`은 유지한다.
- 모바일과 데스크톱 모두에서 현재 상태가 분명하게 보여야 한다.
- 기존 동작은 유지한다: 문서 루트의 `light`, `dark` 클래스를 전환한다.

## 작업 범위

- 다음 구현 Step의 작업 범위를 문서로 정리한다.
- 기존 Next.js, TypeScript, Tailwind CSS, shadcn/ui, npm 스택을 유지한다.
- 가능한 한 기존 지도와 날씨 컴포넌트 구조를 재사용한다.
- 유료 API 제공자, 계정 기능, 인증 기능은 추가하지 않는다.

## 제외 범위

- 모든 국가에 대한 완전한 실시간 API 연동
- 레이더 타일, 위성 이미지, 기상 특보 폴리곤, 예보 애니메이션 재생
- 위 네 가지 항목과 무관한 전체 화면 리디자인
- 새로운 전역 상태 관리 라이브러리 추가
- 패키지 매니저 변경

## 구현 결과

- 지구본 위에 mock 대표 날씨 지점 오버레이를 추가했다.
- 오버레이는 지도 안의 `Weather` 토글로 켜고 끌 수 있다.
- 각 오버레이 마커는 날씨 아이콘, 온도 라벨, 접근성 라벨을 포함한다.
- 오버레이 마커 클릭 시 기존 날씨 상세 패널과 모바일 시트를 열도록 연결했다.
- 왼쪽 상단 `RW` 브랜드 블록의 로고 중앙 정렬과 텍스트 정렬을 개선했다.
- 기본 UI 폰트를 `IBM Plex Sans KR`로 변경하고 mono 폰트는 수치/코드 용도로 유지했다.
- 테마 토글을 텍스트 버튼에서 해와 달 상태 아이콘 버튼으로 변경했다.
- 선택된 날씨 상세 패널이 우측에 유지되면서 상단 컨트롤과 겹치지 않도록 데스크톱 위치를 조정했다.
- 오른쪽 날씨 상세 패널은 선택된 날씨가 있을 때만 표시하고, 닫기 버튼으로 선택 상태를 해제할 수 있게 했다.
- 지도 확대, 축소, Reset 버튼을 왼쪽 날씨 레이어 섹션 아래로 이동했다.
- 지구본 회전 시 뒤쪽 반구의 날씨 오버레이 마커와 선택 핀이 노출되지 않도록 앞면 판정을 추가했다.
- 테마 토글 아이콘을 CSS 조합 대신 명확한 해/달 SVG 아이콘으로 정리했다.

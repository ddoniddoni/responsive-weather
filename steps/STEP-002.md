# STEP-002: 날씨 반응형 버튼 컴포넌트

## 목표

PRD 컨셉에 맞춰 날씨 상태에 따라 시각 스타일이 달라지는 버튼 컴포넌트를 만든다.

## 작업 범위

- 날씨 상태 타입 정의
- `sunny`, `rainy`, `cloudy` 스타일을 지원하는 버튼 컴포넌트 구현
- 메인 화면에서 버튼 스타일 확인 가능하도록 최소 데모 연결

## 완료 기준

- 버튼 컴포넌트가 `condition` 값에 따라 스타일을 변경한다.
- 최소 3가지 날씨 상태 버튼이 화면에서 구분되어 보인다.
- 타입 오류/린트 오류 없이 실행 가능하다.

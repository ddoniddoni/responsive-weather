# STEP-002: 날씨 지도 UI 기반 정리

## 목표

- 지도 중심 화면에서 날씨 레이어, 대표 지점 오버레이, 상세 패널, 테마 전환이 함께 동작하는 UI 기반을 만든다.
- 사용자가 날씨 상태를 빠르게 인지할 수 있도록 마커, 레이어, 패널 표현을 정리한다.

## 작업 범위

- 지도 위 대표 날씨 지점 오버레이를 mock 데이터로 표시한다.
- 날씨 레이어 선택 UI와 하단 시간 선택 UI를 배치한다.
- 오른쪽 상세 패널과 모바일 상세 시트를 연결한다.
- 브랜드 정렬, 폰트, 해/달 테마 토글, 패널 닫기 흐름을 정리한다.
- 지도 컨트롤 위치를 왼쪽 레이어 섹션 아래로 정리한다.

## 완료 기준

- 대표 날씨 지점이 지도 위에 표시된다.
- 사용자가 국가 또는 대표 지점을 선택하면 상세 패널이 열린다.
- 상세 패널은 닫기 버튼으로 제거할 수 있다.
- 라이트/다크 모드는 해와 달 아이콘으로 전환된다.
- 기본 레이아웃에서 스크롤 없이 지도와 주요 컨트롤을 사용할 수 있다.

# STEP-005: 세계 지도 클릭 기반 상세 날씨 패널

## 목표

- 홈 화면에서 세계 지도를 보여주고, 국가를 클릭하면 우측에 상세 날씨를 표시한다.

## 작업 범위

- `react-simple-maps` 기반 세계 지도 컴포넌트 추가
- 국가 선택 상태 관리 및 선택 하이라이트 처리
- 선택 국가 기준 mock 날씨 상세 패널 렌더링
- 모바일/데스크톱 반응형 배치 적용

## 완료 기준

- 초기 진입 시 세계 지도가 보인다.
- 지도를 클릭하면 선택 국가가 강조되고 상세 패널이 표시된다.
- 모바일은 세로 배치, 데스크톱은 가로 배치로 동작한다.

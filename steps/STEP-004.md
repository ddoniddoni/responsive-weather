# STEP-004: 평면 날씨 지도 전환

## 목표

- 지구본 중심 화면을 제거하고 Windy와 유사한 평면 세계지도 기반 날씨 지도 경험으로 전환한다.
- Step 003에서 연결한 Open-Meteo 오버레이 데이터는 유지한다.
- 지도 위 대표 날씨 마커, 지도 이동, 확대/축소, Reset 동작을 평면 지도 기준으로 정리한다.

## 작업 범위

- `geoOrthographic` 지구본 투영을 제거하고 `geoMercator` 평면 지도 투영으로 변경한다.
- 지구본 전용 회전, 뒤쪽 반구 판정, 구형 음영 렌더링을 제거한다.
- `ZoomableGroup`으로 지도 이동과 확대/축소를 처리한다.
- 선택 국가와 날씨 오버레이 마커가 평면 지도 위에 자연스럽게 표시되도록 유지한다.
- README, PRD, AGENTS의 지구본 중심 설명을 평면 날씨 지도 방향으로 정리한다.

## 제외 범위

- 실제 레이더 타일, 위성 이미지, 바람 입자 애니메이션
- 모든 국가 단위 실시간 API 요청
- 오른쪽 상세 패널의 mock 데이터 제거
- 지도 컴포넌트 파일명 변경

## 완료 기준

- 메인 화면에서 지구본이 아니라 평면 세계지도가 표시된다.
- 사용자가 지도를 드래그로 이동하고, 휠 또는 `+`, `-`, `Reset` 버튼으로 확대/축소할 수 있다.
- Open-Meteo 대표 날씨 마커가 평면 지도 위에 표시된다.
- 지구본 뒤쪽 반구 판정 같은 기존 지구본 전용 로직이 제거된다.
- README와 PRD가 평면 날씨 지도 방향으로 갱신된다.
- `npm.cmd run lint`와 `npm.cmd run build`가 통과한다.

# STEP-004: 라이트/다크 모드 토글 구현

## 목표

- 사용자가 라이트/다크 모드를 직접 전환할 수 있도록 테마 토글을 제공한다.

## 작업 범위

- `page.tsx`에 테마 토글 UI 및 상태 관리 추가
- `weather-reactive-button.tsx`에 테마별 버튼 스타일 반영
- `globals.css`의 기본 색상 변수를 클래스 기반 테마로 정리

## 완료 기준

- 토글 버튼으로 라이트/다크 모드 전환이 가능하다.
- 라이트 모드에서 배경, 카드, 버튼 대비가 자연스럽게 보인다.
- 기존 날씨 이펙트(맑음/비/구름)가 모드 전환 후에도 동작한다.

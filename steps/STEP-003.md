# STEP-003: 날씨 시각 효과 버튼 + Step 브랜치 규칙

## 목표

버튼 색상 중심 표현을 줄이고, 날씨 상태별 시각 효과(해 아이콘/비 애니메이션)를 버튼에 직접 반영한다.

## 작업 범위

- `sunny` 상태에서 버튼 구석 해 아이콘 표시
- `rainy` 상태에서 버튼 상단 비 애니메이션 표시
- dark/light 모드 모두에서 효과가 보이도록 스타일 조정
- AGENTS.md에 Step별 브랜치 생성 규칙 추가

## 완료 기준

- sunny 버튼에 해 아이콘이 표시된다.
- rainy 버튼에 비 애니메이션이 표시된다.
- dark/light 모드에서 버튼 가독성이 유지된다.
- Step별 브랜치 규칙이 AGENTS.md에 반영된다.

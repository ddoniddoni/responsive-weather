# Responsive Weather

Responsive Weather는 지도를 중심으로 전 세계 날씨를 탐색하는 Next.js 애플리케이션입니다.

현재 화면은 전통적인 카드형 대시보드보다 지도, 날씨 레이어, 시간 선택, 선택 지역 상세 패널에 더 집중합니다. 사용자는 지구본을 드래그해 회전하고, 국가나 대표 날씨 지점을 선택해 해당 위치의 날씨 상세 정보를 확인할 수 있습니다.

## 현재 방향

제품 방향은 `실시간 지구본 날씨 오버레이`입니다.

기본 지도는 국가와 지역을 선택하는 깔끔한 탐색 화면으로 유지하되, 사용자가 `Weather` 토글을 켜면 지구본 위에 대표 날씨 지점의 compact 마커를 표시합니다. 첫 API 연동 방향은 Open-Meteo이며, 현재 Step 002에서는 mock 데이터로 오버레이 UI와 인터랙션을 먼저 구현했습니다.

## 주요 기능

- 2D 지구본 기반 국가 선택
- 대표 지점 기반 날씨 오버레이 마커
- 날씨 오버레이 켜기/끄기 토글
- 선택 국가 또는 지역의 우측 날씨 상세 패널
- 날씨 상세 패널 닫기 동작
- ADM1 지역 선택 지원
- 기온, 체감 온도, 강수량, 레이더, 바람, 구름, 기압, 습도 레이어 전환
- 지도 확대, 축소, Reset 컨트롤
- 하단 예보 시간 선택 컨트롤
- 라이트/다크 모드 전환
- 데스크톱과 모바일 반응형 레이아웃

## 화면 구성

- `상단 바`: 브랜드, 위치 검색, 현재 레이어/시간 정보, 해와 달 테마 토글을 표시합니다.
- `지구본`: 국가 선택, 지구본 회전, 대표 날씨 오버레이 마커를 담당합니다.
- `왼쪽 레이어 섹션`: 날씨 레이어를 전환합니다.
- `지도 컨트롤`: `+`, `-`, `Reset` 버튼으로 지구본 확대/축소와 초기화를 수행하며, 왼쪽 레이어 섹션 아래에 배치됩니다.
- `Weather 토글`: 지구본 날씨 오버레이를 켜고 끕니다.
- `우측 상세 패널`: 선택한 국가 또는 지역의 현재 날씨를 표시하며, 닫기 버튼으로 선택 상태를 해제할 수 있습니다.
- `하단 타임라인`: 예보 시간대를 선택합니다.
- `모바일 시트`: 모바일 화면에서 선택 날씨 상세 정보를 표시합니다.

## 실시간 오버레이 데이터 흐름

첫 실시간 구현은 Open-Meteo 현재 날씨 데이터를 대표 좌표 기반으로 요청하는 방향입니다.

```txt
대표 날씨 지점
-> Open-Meteo 현재 날씨 요청
-> normalizeWeather()
-> WeatherOverlayPoint[]
-> 지구본 오버레이 마커
-> 마커 또는 국가 선택 시 기존 날씨 상세 패널 표시
```

오버레이 작업 기준:

- 오버레이는 사용자가 볼 수 있는 토글로 제어합니다.
- 모든 국가와 지역의 날씨를 계속 요청하지 않습니다.
- API 응답은 UI에서 직접 사용하지 않고 앱 내부 데이터로 정규화합니다.
- 상세한 날씨 값은 우측 패널 또는 모바일 시트에서 표시합니다.
- 마커는 색상만으로 상태를 전달하지 않고, 아이콘/라벨/접근성 라벨을 함께 사용합니다.
- 지구본 뒤쪽 반구의 마커는 회전 상태에 따라 숨깁니다.

## 프로젝트 구조

- `src/app/`: App Router 페이지와 루트 레이아웃
- `src/components/dashboard/`: 지도 중심 대시보드 조합 컴포넌트
- `src/components/map/`: 지구본, 국가 선택, 지역 지도, 오버레이 마커 컴포넌트
- `src/components/weather/`: 날씨 상세 패널과 날씨 반응형 UI 컴포넌트
- `src/constants/`: 날씨 레이어, 예보 시간, 대표 오버레이 지점 등 상수
- `src/lib/weather/`: mock 날씨 데이터와 날씨 인사이트 로직
- `src/types/`: 공통 TypeScript 타입
- `steps/`: Step 기반 작업 계획과 구현 기록

## 현재 상태

- Step 001에서 실시간 지구본 날씨 오버레이 요구사항을 재정의했습니다.
- Step 002에서 mock 대표 지점 기반 오버레이, 브랜드 정렬, 폰트, 해/달 테마 토글, 패널 닫기, 컨트롤 위치 정리를 구현했습니다.
- 아직 실제 Open-Meteo API 연동은 되어 있지 않습니다.
- 현재 날씨 값은 mock 데이터를 사용합니다.
- 인증, 저장 위치, 사용자 계정, 결제 기능은 없습니다.
